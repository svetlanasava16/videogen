# Этап 6: сценарии дёшево и предсказуемо. Отчёт

План: [docs/ROADMAP.md](../../ROADMAP.md), §6. Справочник: [docs/ENGINE.md](../../ENGINE.md), §12.

## Сделано
### Схема ответа с перечнями из реестра
- `pnpm llm schema script` пишет `data/llm/script/schema.json` (JSON Schema, 40 КБ). Вместо свободных строк в ней только существующее:
  - куклы (состав, говорящий, кто действует, к кому, седоки);
  - роли, места, сублокации, метки (+ `auto`, `off-left`, `off-right`);
  - реквизит, действия, вещи гардероба и причёски.
- Схема — для ограниченной генерации локальной моделью: ошибка «нет такой метки» не сможет появиться при записи.
- Перевод zod → JSON Schema (`pipeline/src/schema.ts`) свой, без новых зависимостей.
- **Самопроверка.** Все 1 800 готовых сценариев проходят схему. Выдуманные кукла, метка, действие и аксессуар отклоняются.
- Ограничение: перечни плоские, метки сразу всех мест. «Метку именно этого места» по-прежнему проверяет `llm check`.

### Линтер `pnpm lint-scripts` (без LLM)

| Правило | Что ищет | Исправляет код |
|---|---|---|
| `mentioned-offscreen` | «это моя жена» / «this is my wife» / «das ist meine Frau», а куклы с этой ролью в сцене нет, хотя место есть | нет → LLM |
| `long-line` | реплика больше трёх строк субтитров (показывается частями) | делит по границе предложения, иначе по запятой или тире; слова те же, только неозвученные эпизоды |
| `no-voice` | у говорящей куклы нет голоса для языка эпизода | нет: это кастинг, в redo не идёт |
| `seat-shared` | двое на одной метке-сиденье | второй садится на ближайшее свободное сиденье того же вида |
| `vehicle-covers` | машина стоит перед говорящим, пока он говорит (по скомпилированному исполнению) | нет → LLM |
| `act-after-line` | рассказчик называет действие («и раз подзатыльник!»), а бит act стоит после реплики | переносит act перед реплику |

- **Исправления детерминированы.** Их же применяет `pnpm llm materialize script`, так что пересборка их не откатывает. Проверено: `materialize` из сценариев даёт ровно те же 1 800 файлов, что `lint-scripts --fix`, байт в байт.
- **Правила, которые код не исправит** (`mentioned-offscreen`, `vehicle-covers`), сообщает `pnpm llm check` — сценарист видит их при записи.
- **В промпте** сценариста — раздел «Lint rules».
- **`--redo`** пишет эпизоды, оставшиеся для LLM, в `data/llm/script/lint-redo.txt`.

## Результат на всей базе (1 805 эпизодов)
- **Исправлено кодом 803 реплики в 519 эпизодах** (все — деление длинных реплик). Озвучка нигде не потеряна, ни один озвученный эпизод не изменён. Текст анекдота (все реплики подряд) совпадает с исходным в каждом эпизоде. Пример:
  - было: «Я выиграл в лотерею десять миллионов рублей! Куплю себе для начала хорошую двухкомнатную квартиру.» (3 части субтитров);
  - стало: «Я выиграл в лотерею десять миллионов рублей!» + «Куплю себе для начала хорошую двухкомнатную квартиру.» — тем же голосом, подряд.
- **Осталось для LLM: 99 эпизодов.**
  - 98 — с репликой, которую не разделить без изменения слов (нет ни конца предложения, ни запятой в середине);
  - 1 — «это мой папа», а папы в кадре нет (`en-r-c0w5e9.ru`).
- **Озвученные эпизоды в список не попадают.** Переписать текст — значит переозвучить (платно), поэтому у них длинная реплика только в сведениях. Это 7 эпизодов из отладочного набора.

  Список — `data/llm/script/lint-redo.txt`. LLM я **не запускал**: перед прогоном назову объём и оценку токенов.
- **Голосов нет:** 2 402 случая в 1 245 эпизодах. Это кастинг (`pnpm voice cast`), не сценарий.
- **Двое на сиденье, машина перед говорящим:** 0. **Действие после реплики:** первая версия правила нашла 2, но это была ложная тревога. Правило уточнено: если следующая реплика тоже называет действие («Стучит, стучит…»), всё стоит верно. После уточнения — 0.
- **Отладочный набор:** изменились 2 неозвученных эпизода (`en-r-b3n4or.en`, `ru-7a52a7aaa74f.de`) — в них разделены длинные реплики. Эталоны пересняты.
